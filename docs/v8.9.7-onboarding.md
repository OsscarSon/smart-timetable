# v8.9.7 新手引导

基于 Mochi Onboarding Design v1，在现有 `wizard.js` 上增量改造，没有覆盖任何文件。
- 新增 3 个介绍页放在原来 5 步之前：欢迎+语言、空间（Study/Work/Life 多选，复用 `MochiNext.mountWizardChoices`）、功能介绍（含可选的“想做的一件事”）。
- 原来的 5 步（导入选择、日历习惯、学校节次、外观、完成）、`wzApply/wzDone`、`SET.wiz`、`loginGate`、`MochiNext.startTour` 全部保留。语言 chips 从“导入”页移到欢迎页。
- 重新运行向导（设置里）从“导入”开始，不重复介绍页；老用户不会被强制重新引导。
- 介绍页上的 Skip 跳到“导入”页，不会跳过初始化；之后页面的 Skip 行为不变。
- 目标草稿只存本机 `onb-goal-draft`（非 mochi- 前缀，不同步），不写入 Goals / 日历 / 云。
- 向导里选过空间后，引导结束不再重复弹模式选择。
- 文案：`js/lang-onb.js`（en / zh / ms）。

未验证：真机视觉、320px 小屏、Android WebView、离线重开。Goals 草稿尚未接到 Goals 编辑器（设计包要求另立阶段并确认）。
