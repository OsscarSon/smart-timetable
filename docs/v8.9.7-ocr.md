# v8.9.7 · 拍照识别课表：新增“本机 OCR”（Tesseract.js）

## 它是什么
AI 助手 →「拍照课表」里多了识别方式：
- **☁️ 云端 AI（默认，和以前一样）**：Gemini，更准，图片会发到后端。
- **🔤 本机 OCR（新）**：开源 [Tesseract.js](https://github.com/naptha/tesseract.js)（Apache-2.0），**免费，图片只在这台设备上处理，不上传**。文字语言可选「English / Bahasa」或「中文 + English」。

默认仍是云端；**没选本机 OCR 之前不会加载任何 OCR 代码**。

## 流程（识别结果只是“候选”，必须核对）
1. 第一次使用先弹**同意框**（要下载识别引擎和语言包，约 10–15 MB，只下载一次、之后可离线用；图片不上传）；拒绝 = 什么都不加载、零写入。
2. 预处理（在浏览器画布里）：最长边压到 2200px → 灰度 → 拉伸对比度 → **擦掉表格线**（见下面的测量，这一步最关键）。
3. Tesseract.js 6.0.1（固定版本，从 jsDelivr 按需加载），稀疏文字模式（PSM 11），取回 TSV，识别完立刻 `terminate()` 释放内存。
4. `js/ocr.js` 的解析器把“文字 + 位置”还原成课程：星期表头 → 列；左边的时间标签 → 行；单元格文字 → 名称 / 教室 / 老师；休息行跳过；相邻同名 / 跨行的合并成一节。支持中文、英文、马来文的星期名（含 OCR 错字的模糊匹配）；24 小时 / 12 小时（带或不带 AM/PM）；区间 / 只有开始时间 / 上下两行叠放的标签；没有网格时按“一行一节”兜底。
5. 进入**核对模式**：原图缩略图（点一下放大）+ 每节课一行可编辑（星期、开始、结束、名称、教室、勾选）。**把握低（<60%）、或时间是猜的，默认不勾选并标红**；没放进课表的文字放在折叠区里让你看到。
6. 点「加入」才写入：名称不能空、结束必须晚于开始，否则整行标红、拒绝写入；写入前 `Undo.snap()`，写入后弹**可撤销**提示。（顺带：云端拍照路径以前没有撤销，现在也有了。）

## 测量（真实 Tesseract + 合成课表，不是真实照片！）
用系统自带的 Tesseract 5.3（eng）对 **60 张合成课表**（英文 / 马来文、有无格线、彩色格子、多种时间写法、可选教室 / 老师、休息行、模糊 / 噪点 / JPEG / 轻微旋转）实测：

| | 召回 | 精确率 |
|---|---|---|
| 第一次测量（无预处理、早期解析器） | 61% | 72% |
| **现在**（预处理擦格线 + 解析器改进） | **87%** | **87%** |

（召回 / 精确率的判定：星期相同、开始 / 结束误差 ≤ 5 分钟、名称相似度 ≥ 75%。）现在的分项：名称对 92%、时间对 94%；合并的“双节连堂”格 7/7；弱项是“上下两行叠放的时间标签”（73%）和“每格带教室 / 老师两行”（81%，名称容易被多行干扰）。页面分块模式对比：PSM 11（稀疏文字）87%、PSM 3（自动）82%、PSM 6（单块）65%，所以用 11。

**这个数字是上限**：合成图比手机拍的照片干净得多（没有透视、阴影、反光、手写、复杂背景）。真实照片会更差——所以才强制“逐项核对 + 可编辑 + 低把握不勾选”，而不是自动导入。

测试发现并修掉的真问题：中文逐字 OCR 会让解析器崩溃；只有开始时间时最后一行时长算少；12 小时制被个别读错的标签连累；“核对列表”在对话框里被挤成一行高（现在核对模式会收起页签 / 说明）。

## 没做到 / 没验证（请知悉）
- **WASM 引擎本身没有在沙箱里跑**：这里不能联网下载 Tesseract.js 和语言包。端到端测试里引擎是“桩”，返回的是真实 Tesseract 在同类图片上的 TSV；界面、预处理、解析、核对、写入、撤销、隐私都是真的。**请在你自己的浏览器 / 手机上用真实课表照片试一次**，特别是：加载速度、内存、中文识别。
- **中文和马来文的真实识别准确率没测**：沙箱只有英文语言包。马来文用英文模型识别（字母相同），中文要下载 chi_sim；中文解析逻辑有单元测试（逐字拼接、周一…周五），但中文 OCR 本身的准确率未知。
- 手机 App（Capacitor）里需要联网下载一次引擎（语言包之后缓存在本机）；没做“随 App 打包离线引擎”。jsDelivr 在中国大陆可能被墙。
- 不支持：歪斜 / 透视很大的照片（格线擦除和列对齐都假定基本摆正）、“星期在左边、时间在上面”的转置课表、手写课表、没有任何时间标签的课表（只给猜的时间并全部标红）。
- 合并格（连堂）靠“文字垂直居中在两行交界处”判断，可能出错——核对时看时间。
- 国际化：拍照面板新增文案三语齐全；对话框里页签（“一句话 / 拍照课表 / 整周重排”）本来就没有手工英文 / 马来文翻译，这次没动。

## 开关 / 回滚
- 用户侧：识别方式选“云端 AI”即回到以前的行为。
- 代码侧：`index.html` 去掉 `js/ocr.js` 的 script 标签 → `window.OCR` 不存在 → 识别方式选择整块自动隐藏，一切退回云端路径（`ai.js` 里全部用 `window.OCR` 守卫）。
