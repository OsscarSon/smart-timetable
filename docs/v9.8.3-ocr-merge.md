# 把 v8.9.7「本机 OCR」合并进 v9.8.3

**底板**：v9.8.3。**带入**：v8.9.7 的本机 OCR（详见 `docs/v8.9.7-ocr.md`）。

## 冲突点
v9.8.3 里已经有一套旧的 OCR（浏览器 OCR 出文字 → 把文字发给云端 AI 整理，`api/ai.js` 的 `mode:'ocr'`）。
v8.9.7 是纯本机方案（预处理擦格线 → Tesseract.js 6.0.1 → `ocr.js` 解析器 → 逐项核对 → 写入可撤销）。
两套不能并存（同样的元素 id、同一个识别方式开关），所以**用 8.9.7 替换旧方案**。

## 改动
- `js/ocr.js`：换成 8.9.7（Tesseract.js 5.1.1 → 6.0.1 固定版本，带解析器和 `OCR.recognize`）
- `js/ai.js`：拍照部分换成 8.9.7（同意框、核对模式、校验、`Undo.snap/toast`；云端拍照写入也可撤销）
- `index.html`：拍照面板换成 8.9.7 的识别方式 / 文字语言选择；删掉旧的文字校对框
- `css/style.css`：追加核对列表 / 核对模式样式
- `api/ai.js`：删掉旧的 `ocr` 模式和 `OCRP`（与 8.9.7 一致）
- `js/lang-ocr.js`：换成 8.9.7 新文案的三语翻译（`lang-ui.js` 里 9.8.2 补的其它翻译不动）
- `js/about.js`、`js/aisrc.js`、`js/faq.js`、`js/lang-ui.js`：把“拍照识别只能走云端”改成“默认云端，也可改用本机 OCR”；关于页的开源列表加上 Tesseract.js
- `scripts/check.mjs`：加回 8.9.7 的 OCR 边界规则；`README.md` 加 Tesseract.js 一行
- `tests/ocr-unit.cjs`、`tests/ocr-smoke.cjs`、`tests/ocr/`（评测脚本 + 夹具）、`docs/v8.9.7-ocr.md`

## 验证
`ocr-unit` 18/18、`ocr-smoke` 31/31、`check` 通过；9.8.3 原有的 about / merge / empty / focus / goals / goals-sync / study-space / buddy / wrapped2 等冒烟与单元测试全部通过。

## 没做
- 版本号仍是 9.8.3（`version.js` / `package.json` / `sw.js` 的 `VER` 都没动）。已安装的用户要拿到新文件，发布时请同步升版本（例如 9.8.4）。
- 真实 Tesseract 引擎在沙箱里没跑（同 8.9.7 的说明），请用真实课表照片在手机 / 浏览器上试一次。
