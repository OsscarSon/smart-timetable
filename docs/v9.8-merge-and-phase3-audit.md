# v9.8.0 · Phase 3 合并进 main，以及 3A / 3B / 3C 验收

## 一、合并了什么
三个版本的关系：**v9.6** 是共同的起点；**v9.7.0** 是 Phase 3（Study Space）；**main（9.7.1）** 是另一条线（Starter Kits、插画横幅、菜单润色、无障碍补丁）。两条线是平行的，所以用 v9.6 做基线做了三方合并，没有整个文件覆盖。

| 类别 | 文件 | 处理 |
|---|---|---|
| Phase 3 新增 | `css/study-space.css`、`js/study-space.js`、`js/study-space-core.js`、`js/lang-study-space.js`、3 个测试、3 份文档 | 直接加入 |
| 只有 Phase 3 改过（main 没动） | `js/app.js`、`scripts/check.mjs`、`README.md` | 取 Phase 3 的版本（已先确认 main 与 v9.6 相同） |
| 两边都改过 | `index.html`、`js/menu.js`、`js/version.js`、`package.json`、`sw.js` | 三方合并；`menu.js` 自动合并成功，其余 4 处冲突人工解决 |
| main 独有 | Starter Kits、`menu-polish.css`、两张横幅图、`native/` 等 | 原样保留 |

**4 处冲突的解决：**
- `index.html`：样式引用两边都要（`starter-kits.css`、`menu-polish.css`、`study-space.css`）。
- `sw.js`：以 main 的清单为底，加上 Phase 3 的 `study-space.css`、Buddy 两张 SVG、三个 `study-space*` / `lang-study-space` 脚本。
- `js/version.js`、`package.json`：版本号见下。

**版本号：9.8.0。**9.7.0（Phase 3）和 9.7.1（main）已经各指一个不同的包，合并后用新的 9.8.0，避免撞号。版本号三处（`version.js`、`package.json`、`sw.js` 缓存名）一致，`npm run check` 会检查。

**为适配新版本号改了一处测试：**`tests/study-space-smoke.cjs` 里原来把缓存名写死成 `mochi-v9-7-0`，改成从 `package.json` 读取。

**需要你确认的一点：视觉。**实现没有照搬设计稿的固定色和字体，而是用 App 现有的主题变量调出相近气质，所以深色模式、主题色会自动跟随。和设计稿相比有几处明显不同：科目卡用字母徽章而不是 📐⚡🌿 这样的 emoji；欢迎语是 “Good morning / 5 things need you today” 而不是设计稿里更俏皮的文案；没有引入 Nunito / DM Sans 字体。**没有和设计稿做过像素对比，是否符合你的预期请你看截图确认**（`docs/v9.8-screenshots/`）。

## 四、合并中发现、没有改动的问题
1. **Starter Kits 的条数和说明文档不符。**main 的两份说明都写“每套 35 条”，实际是 40 / 40 / 40 / 33。测试按代码里的模板定义检查，没有改模板。
2. **`css/event-cards-polish.css` 没有被任何文件引用。**它的注释写着是 v9.7.1 的周视图卡片润色，但 `index.html` 没有链接它，可能是漏接。我没有擅自接上（改的是周视图，我没法判断你想不想要）。
3. **`js/fcview.js`、`js/guide.js`、`js/rough.js`、`js/widget.js` 和 `native/android-widget/` 也没有接入。**它们原样留在包里，没有影响运行。其中 widget 还需要 Capacitor 的 Preferences 插件和原生部分配合。
4. **`js/config.js` 带着真实的 Supabase 地址和 publishable key**（main 的内容，v9.6 里是空的）。我原样保留了。publishable key 本来就设计成放在前端，但如果这个包要公开发布，请你知悉。
5. **`HW` 数组里出现 `null` 会让 `notifyset.js` 启动时抛错，整个页面起不来。**这是 Phase 3 之前就有的脆弱点（Phase 3 的报告也提到了），Study Space 自己对坏数据是容错的。真实使用里不太会出现，但值得单独加固。
6. Starter Kits 的撤销只在导入对话框关闭前有效，关掉后就不能撤销（它自己的说明里也这么写）。

## 五、回滚
Phase 3 和 main 的改动互相独立：去掉 Phase 3 只需删除 `index.html` 里 `study-space` 相关的样式 / 脚本引用、`#v-ss` 和设置里的“学习空间”分类，再还原 `js/app.js`、`js/menu.js` 的一行；没有新增任何同步数据，不会留下残留。
