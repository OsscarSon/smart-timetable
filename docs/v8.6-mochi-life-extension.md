# Mochi Smart Timetable · Study / Work / Life 扩展说明

这是基于原 v8.6 源码的**增量功能包**，保留 Claude 编写的原有核心文件结构。未替换原来的日程算法、数据库及 AI 接口。

## 三层架构

1. **Core Timetable**：使用原来的课程/活动周视图、任务、提醒、AI 重排、云同步和历史存储。
2. **User Mode**：新用户在原首次向导第 1 步选择 Study、Work 或混合；旧用户可在菜单 → 个人配置 → 使用场景与模式切换。此版本主要切换标签及入口，不会删除任何原记录或强制改变已有课表类型。
3. **Life Management**：更多 → 生活管理。统一访问运动、饮食、护肤、原始日程，并提供 Energy / Wrapped。这个层次不受 Study / Work 选择影响。

## 新模块

- `js/mochi-next.js`：模式、Energy、Wrapped、引导和 Chrono 日期识别提示。只使用新的 localStorage keys：`mochi-profile`、`mochi-energy-v1`。
- `css/mochi-life.css`：独立样式层，使用原 CSS 颜色变量，不修改现有样式。
- `assets/study-mode.webp` 和 `assets/work-mode.webp`：两张新生成、压缩过的原创配图。
- `Driver.js`：菜单 → 个人配置 → 新手引导，联网或 Android build 后可用高亮逐步引导，加载失败退回纯文字说明。需要 `npm i` 安装依赖，打包脚本会把 JS 和 CSS 放进 `www/vendor`。
- `Chrono-node`：AI 一句话弹窗附加时间识别预览，日期解析不会直接写日程。安卓版由 `esbuild` 自动打包为本地库；未打包网页版会在线动态加载英文日期解析包，若失败仍有基础中文时间识别和原 AI 解析。
- `Mochi Energy`：用户手动选择每天的 High/Medium/Low 状态；提供不破坏原日程的建议。**本版不会私下自动调整日程**。
- `Mochi Wrapped`：统计**当前课表、当月本地保存的手动安排**（计划时数、已标记完成、当月完成任务、日程活跃天数）；可导出原创 Instagram Story 比例 PNG。不会把计划时数伪装成真实工作/学习时数。固定课程、重复事件、其他课表及未记录的活动不纳入本版统计。

## 兼容性与构建

在项目目录运行 `npm install`、`npm run check`、`npm run build:www`。原 `sw.js` 已加入新 CSS / JS / 插画并更新缓存版本；`build-www.mjs` 会复制新资产、打包 Chrono-node、复制 Driver.js 到离线版。

**验证范围**：本次 `npm run check` 通过（检查 JavaScript 语法、引用和 service worker 预缓存）。由于执行环境无法从 npm registry 下载依赖，也无法通过受限 Chromium 访问本地测试页面，**未完成实际浏览器端到端或 Android 构建验证**。请在能联网的开发机运行上述构建命令、检查首次向导 / 任务 / AI / 云同步，并先备份已有数据再更新线上版本。

## 回滚

新增功能在 `js/mochi-next.js` 和 `css/mochi-life.css`；删除相关 `index.html` 引用、模式新入口并还原改动的 app.js、menu.js、wizard.js、sw.js 后可退回 v8.6 原始行为；原始备份 ZIP 建议保留。
