# Mochi v6 → v7：改进清单完成情况

对应 `mochi-docs.zip` 里的《Mochi 改进清单》。**验证方式**：在无头 Chromium（Playwright）里用手机 / 平板 / 横屏尺寸实际跑过；后端用假的 req/res 单独测；云同步用内存版假 Supabase 测冲突路径。
**没有验证**：Android 原生部分（桌面小组件、通知渠道、精确闹钟）——这个环境没有 Android SDK / javac，只写了源码；真机行为我没见过。

图例：✅ 做了并测过　🟡 做了但没法在这里验证　⬜ 没做

## 3. 功能差异

| 项 | 状态 | 说明 |
|---|---|---|
| 桌面小组件 (P0) | 🟡 | `android-widget/`（Java）：当前 / 下一节 + 系统倒计时 + 后续几项，今天没了显示明天；网页端 `native.js` 推数据。**未编译、未真机运行**。`npm run android:widget` 一键装进 Capacitor 工程。 |
| 分钟级时间 (P0) | ✅ | 活动 / 重复活动 / AI 输入输出 / 提醒 / .ics 全部改为 `s`、`e` 分钟；周视图点空白按 15 / 30 分钟吸附；编辑页用时间选择器 + 时长快捷键，改开始时间时结束时间顺延。旧数据（整点）首次打开自动迁移，已用旧格式数据验证（含完成标记）。 |
| 通知 (P0) | ✅ 网页 / 🟡 手机 | 课前 N 分钟、作业截止（当天几点 + 前一晚 20:00）、提示方式（声音+振动 / 仅振动 / 静音）、精确闹钟检查按钮、电池优化与各品牌自启动指南。提醒清单的生成逻辑已测；Android 渠道 / 精确闹钟需真机验证（尤其“仅振动”渠道的实际表现）。网页版“仅振动”做不到单独关声音。 |
| 周视图排版 (P0) | ✅ | 见第 4 节。 |
| 安装形态 (P0) | ✅ 网页 / ⬜ AAB | 新增 `manifest.json`、192 / 512 / maskable / apple-touch / svg 图标、`sw.js` 离线缓存（已测：断网重载能打开）。**AAB 没法在这里打**（需要 Android Studio 和你的签名密钥），README 写了完整步骤，`package.json` 已列好依赖。 |
| 云同步 (P1) | ✅ | `mochi-wk` 拆成按周存储（`mochi-wk:<课表>:<周号>`，旧数据自动拆分）；同步加“基准版本”判断，真冲突时提示选“用云端 / 保留本机”；“完成记录”自动合并。已用假 Supabase 测过：只有冲突的那一周提示，云端单方改的周静默拿下。 |
| 视图自定义 (P1) | ✅ | 视图密度（紧凑 / 标准 / 宽松）、吸附 15 / 30、折叠周末列、列表里显示 / 隐藏教室和老师；横屏 / 平板双栏。 |
| 1–4 周轮换 (P2) | ✅ | 核对结论：重复活动按各自起始日期计算，不受“轮换周数”切换影响，不会错位；已在设置里写明。 |
| 附件 (P2) | ✅ | 备份页写明“普通备份不含附件”，并新增“导出（含附件）”，导入时一并还原。 |
| 分享 (P2) | ⬜ | “实时共享”没做（原清单也说可延后）。 |
| 日历同步 (P2) | 🟡 | 只做了 .ics 的修复：假期日期写入 EXDATE，固定课程按学期起止日期截断，并修了“多周循环但没选周的课被写成隔周”的问题（已测）。**Android 系统日历读写没做**（需要原生插件）。 |
| 搜索 (P2) | ✅ | 全局搜索：课程 / 教室 / 老师 / 所有周的活动 / 重复活动 / 作业 / 提醒，点一条直接跳转。 |
| 可穿戴 / 语音 / 变现 (P3) | ⬜ | 按清单暂不做。 |

## 4. 排版与界面

| 区域 | 状态 | 做法 |
|---|---|---|
| 周视图格子 | ✅ | 细分隔线（整点实线 + 半点淡线）、事件色块按分钟定位、当前时间红线、固定课程斜纹、完成划线；周末列可折叠（再点日期头展开）。同列重叠的块自动并排。 |
| 滚动方式 | ✅ | 去掉卡片内嵌套滚动，页面只有一个滚动条；日期头吸顶；切到周视图 / 点“今天”会滚到当前时间附近。 |
| 顶部区域 | ✅ | 问候卡 + 周标题卡合并成一条顶栏（≡、问候 + 日期、🔍、醒目的“今天”按钮）。 |
| 悬浮按钮 | ✅ | 合并成一个 ＋，点开选：手动添加 / 一句话 AI / 拍照导入。 |
| 操作按钮 | ✅ | ‹ 今天 › 用主题色；复制到下周、折叠周末、清空收进“⋯”；清空要确认两次并显示条数。 |
| 平板 / 横屏 | ✅ | ≥768px 双栏：左周视图，右当天详情 + 提醒 + 近期作业；其他页面居中限宽。1100×800、844×390 实测。 |
| “更多”页 | ✅ | 只剩入口列表；“AI 助手”统一一句话 / 拍照 / 整周重排；去掉旧的记录卡和版本号标题。 |
| 设置页 | ✅ | 分类列表 → 二级页（外观与显示 / 课表与课程 / 假期 / 通知与提醒 / 账号与同步 / 数据）；标题样式统一成 class。 |
| 底部导航 | ✅ | 课表 / 作业 / 学习 / 统计 / 更多；“提醒”并入课表页的今天面板。 |
| 首次向导 | ✅ | 第一步先问“拍照导入 / 手动添加第一节课 / 先逛逛”，完成后直接打开对应界面；主题挪到倒数第二步。 |
| 空状态 | ✅ | 整个课表还没内容时，日视图和周视图都给“拍照导入课表 / 添加第一节课 / 一句话添加”。 |
| 字号与对比度 | ✅ | 小字最小 12px（原来 9–11px），正文 ≥14px。对比度实际计算过：辅助灰字 2.9:1 → 5.4:1；主色按钮上的字改用深色（白字只有 2.3:1，深色 6.9:1）；用主题色写的文字自动加深 / 提亮到 ≥4.5:1（自选主题色也会自动算）。**“跟随系统字号”没做**（需要把 px 全改成 rem，改动面太大）。 |
| manifest | ✅ | 见上。 |
| 样式代码 | ✅ | `index.html` 里已没有内联 `style=`（`npm run check` 会检查）；样式用变量；加 ≥768px 断点。 |

## 已知局限
- 周视图里没做拖拽 / 拉伸改时间（点开编辑页改）。
- 网页版的通知只在页面开着时弹；后台靠 App。
- “仅振动”通知渠道的实际表现取决于手机厂商，请真机试。
- 云同步冲突是“整份选一边”（按周），没有做到活动级合并。
