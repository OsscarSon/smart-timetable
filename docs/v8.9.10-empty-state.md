**改了什么**：整个课表还没有任何内容时，原来的「还没有任何安排 🐱 + 说明 + 三个按钮」整块去掉，只留一只大猫当背景插画（没有文字、没有按钮）。
右下角的 ＋ 菜单本来就有同样的三个入口（手动添加 / 一句话 / 拍照导入），所以没有丢任何功能。

- 日视图和周视图都一样；猫不挡点击（周视图里点格子照常能用）。

- 读屏软件会读「还没有任何安排」（en / zh / ms）。
- 一加日程，猫就消失；删光又回来。
