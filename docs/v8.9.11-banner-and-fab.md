# v8.9.11 · 横幅不再自相矛盾 + ＋ 轻轻提示

接在 v8.9.10（空状态只留一只猫）之后。

## 1. 今天没有任何安排时，不再说「都完成啦」
- 以前：今天什么都没排，顶部横幅还是显示「🎉 今天的事都完成啦！」，下面橙色卡片又说「今天没有安排」。重复，而且前一句是在夸一件没发生的事。
- 现在：今天没有任何安排（没有手动活动、重复活动、固定课程、提醒）→ 不显示「都完成啦」。
  - 有未完成的 → 「📌 今天还有 N 件事」（不变）
  - 有安排且全做完 → 「🎉 今天的事都完成啦！」（不变）
  - 没安排但有考试倒计时 / 作业到期 → 只显示考试 / 作业那一段
  - 什么都没有 → 横幅整条隐藏（`.bnr:empty` 本来就会隐藏空横幅）
- 文件：`js/remind.js`（bnr 函数）。
