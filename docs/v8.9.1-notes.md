# v8.9.1

新用户流程：① 登录屏（可跳过；仅在配置了 Supabase、Google 登录可用、非手机 App、未登录时出现；点过一次就不再出现）→ ② 5 步向导 → ③ driver.js 引导 → ④ 学习 / 工作 / 生活 模式选择。
向导里点「跳过」也会走 ③④。修复：向导完成后写入的 `mochi-mode-after-wizard` 标记以前没人读取，引导和模式选择不会出现。

已知限制：在新设备上用 Google 登录回来的老用户，本机仍是“全新”状态，会看到向导（可点跳过）；云端数据同步后才会出现。
