# Mochi v8.8 — Integration and localization fixes

- Study, Work and Life cards now support multi-selection with one shared timetable. An existing `mochi-profile` mode migrates lazily; nothing in schedule data is rewritten.
- Removed the redundant Life Management page and menu entry; existing sports, health, diet, skincare and calendar remain in their original screens.
- Combined tour and mode selection under one menu entry; finishing the Driver.js tour opens the multi-select selector. First-run wizard also offers these choices without removing its original setup steps.
- New feature UI uses direct English, Chinese and Malay strings via `ui-lang` instead of relying on machine translation. Existing UI uses the original translation system.
- Updated original Features & open source page with Driver.js, Chrono, Energy, Wrapped and selectable modes.
- Updated menu footer, package version and service-worker cache key to v8.8; added Life illustration to offline shell.
- Energy suggestions do not change the timetable. Wrapped uses saved manual events, not actual elapsed time. Chrono preview does not replace existing AI confirmation.
- Existing Claude-origin core schedule modules, cloud sync and storage layouts were not refactored.
