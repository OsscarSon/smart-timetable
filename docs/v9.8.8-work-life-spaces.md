# v9.8.8 · Work Space / Life Space

把设计包 `Mochi_Work_Life_UI_Claude_Design_Pack` 的 Work / Life 页面接进正式项目。视觉参考 `preview.html`，数据全部来自现有功能。

## 入口与路由
- 新增两个视图 `wk`（Work Space）、`lf`（Life Space），和 Study Space 一样归在底部「学习」那一格的分组里（`GRP`），所以进去后底部标签保持高亮，也不会多出第六个标签。
- 底部「学习」标签的落点**不变**（仍先进学习空间）；选了「工作 / 生活」模式后，学习空间顶部会出现切换条（📚 学习｜💼 工作｜🌿 生活），三个空间页顶部都有同一条。只选学习时没有切换条，和 v9.8.7 完全一样。
- 没有新增汉堡菜单，也没有盖住底部导航或 ＋ 按钮。

## 数据口径（全部只读，页面里没有任何模拟内容）
| 位置 | 来源 |
|---|---|
| Work · 今日安排 / 下一项 / 今日流程 | 现有课表：手动安排 + 重复活动（`WK` / `rpBlocks`），完成状态读 `DN`。固定课程不算；自动排的学习时段（`a:1`）和属于“学习”目标的关联时段不算（它们属于学习空间） |
| Work · 本周已排时间 | 同上，每天时间区间取并集再求和。明确标注是“已排”，不是实际工作时长 |
| Work · 进行中的目标 | `Goals.core`：`space = work` 且进行中；进度、截止天数用 Goals 自己的函数；Goals 关闭时整张卡片隐藏 |
| Life · 小小的日常打卡 | 健康页的护肤步骤（`BT`），勾选时走现有的 `btSave()` + `rBt()`，和健康页是同一份记录 |
| Life · 饮水 | 健康页的饮水（`DI`），＋/－ 走现有的 `diSave()` + `rDi()` |
| Life · 精力 | Mochi Energy 的现有记录（`MochiNext.energyToday()`，没记录就显示 —），点击打开现有精力弹窗 |
| Life · 温柔的日程 | 同一份课表：今天还没发生的 + 明天未完成的 |
| 添加活动 / 安排自己的时间 | 现有活动编辑器 `addOnDay()` |

**没有**新建任何日程 / 习惯 / 项目数据，没有新的存储键，没有写 `mochi-*` / `goals-*` 之外的任何东西；只是浏览三个空间时，所有数据一个字节都不变（测试 7.5 验证）。

### 设计包里有、但这次没有做的（现有数据不支持，宁可不放）
- Work 的 Focus session、Daily reflection、“Project pulse”里的模拟项目：项目进度改用真实的 Goals。
- 按“工作 / 生活”分类统计活动时长：现有活动没有分类字段，不去猜。所以 Work 和 Life 读的是同一份课表，只是角度不同（全天流程 vs 接下来的安排）。
- 预览里的示例文字、假头像、假数字。

## 无障碍 / 响应式 / 主题
- 语义标题、`role="progressbar"`、复选框原生 `input`、切换条 `aria-pressed`、`:focus-visible` 轮廓；勾选后键盘焦点保持在原来的控件上。
- 触控目标 ≥ 44px；320 / 360 / 390 / 768 / 1280 宽度无横向溢出；手机 hero 约 160–190px，平板 / 电脑更大并改两栏。
- 颜色全部来自现有主题变量（焦糖 / 苔绿只是 `color-mix` 调出的色调），深浅色、主题色自动跟随；`prefers-reduced-motion` 下没有过渡。
- 英 / 中 / 马三语，文案在 `js/lang-spaces.js`，`npm run check` 会检查三种语言键一致。

## 改动的现有文件（都很小）
- `index.html`：两个 `<section>`、一个 CSS、三个 script。
- `js/app.js`：视图列表和分组各加 `wk`、`lf`。
- `js/mochi-next.js`：导出 `energyToday()`；选模式 / 选精力后触发 `mochi:modes` / `mochi:energy` 事件（只通知刷新，不带数据）。
- `js/faq.js`：把“学习 / 工作 / 生活模式”那条的回答补上空间页说明（条数不变）。
- `sw.js`、`js/version.js`、`package.json`：预缓存新文件，版本 9.8.8。
- `scripts/check.mjs`：新增静态规则（聚合层必须是纯函数；界面层不许读写本机存储、不许出现数据键字面量；三语键一致；CSS 必须带命名空间）。
