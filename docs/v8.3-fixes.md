# v8.3 排版修复

| 现象 | 原因 | 做法 | 怎么验证的 |
|---|---|---|---|
| ＋ 按钮“被固定”、跟着页面走 | `html[data-wp] .card{backdrop-filter}`：带 backdrop-filter / transform / filter 的祖先会成为 `position:fixed` 子元素的定位基准。按钮在 `section.card` 里，所以只在开壁纸时出问题 | `#fab` / `#fabm` 移到 `.app` 外；`showView()` 在 `body` 上写 `data-view`，CSS 只在课表页显示 | 开壁纸、滚动 900px：按钮底部始终 624px（视口内）。全页扫描所有 `position:fixed` 元素，没有别的被带走 |
| 橙色线乱跳 | `js/rough.js` 用 MutationObserver 监听整个 body，任何 DOM 变化（包括每 30 秒刷新倒计时）后 500ms 清掉所有线再重画，每次形状随机；线是绝对定位的兄弟节点，弹窗滚动时不跟着走 | 删除 rough-notation 与 `js/rough.js`；改成 `::after` + SVG mask 的固定手绘线 | About 弹窗滚动 300px，标题与线一起移动；两种尺寸下无报错 |
| 红色当前时间线 | `.wk-now` 写死 `#e5484d` | 淡线贯穿全周 + 今天一列加粗发光 + 时间轴上的时间标签（`nowLine()`，`.wk-now-d` / `.wk-nt`） | 时钟固定 14:32，手机 / 宽屏、浅色 / 深色截图；标签在时间轴内；点线旁空白仍能新建 |
| About 弹窗“Features”压住上一段 | `.dlg` 是纵向 flex + `max-height`，内容超高时 `.msg` 被压缩（18px，文字需要 51px），文字溢出被盖住 | `.dlg>.msg,.dlg>h2,.dlg>h3,.dlg.ab>*{flex-shrink:0}` | 扫描全部弹窗（390×520 / 700×560）：被压扁的子元素 0 个 |

没有验证：真机（Android WebView）上的 backdrop-filter 与 mask 表现；这个环境只有 Chromium。
