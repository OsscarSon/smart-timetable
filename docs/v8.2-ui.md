# v8.2 界面美化改动

- **图标统一（js/icons.js）**：全项目 emoji 换成 Lucide 线条图标。不改任何文字内容；在翻译完成之后再替换（词典是按“带 emoji 的整句”匹配的）。库没加载到时保留 emoji。输入框 / 下拉选项 / placeholder 放不了图标，只去掉 emoji。
- **语言栏（js/langrow.js）**：菜单、更多页、设置里都是一行“Language · 语言 › 当前语言”，点开底部列表选择（向导第一步仍用小按钮）。
- **壁纸（js/wallpaper.js）**：5 款跟主题色走的内置图案（纯 CSS）+ 自选照片（压缩到 1080px，只存本机，不同步）+ 浓淡滑块。开启后卡片半透明磨砂。
- **菜单 / 更多页**：共用一份分组清单（AI 与工具 / 个性化 / 课表与数据 / 关于 Mochi）；“更多”页不再只有 4 行。
- **样式**：底栏磨砂 + 选中药丸；入口图标放进淡色圆角方块；标题图标对齐主题色。
- **顺手修的 bug**：js/aisrc.js 比 core.js 先加载却用了 el()，导致“设置 → AI 来源”的按钮一直渲染不出来（也让“自己的 key / 优先本机 AI”两个开关失效）。
- 新增文件：js/lang-new.js（新增文字的 en / ms 翻译）、js/langrow.js、js/wallpaper.js；sw.js 缓存版本 mochi-v8-2。
