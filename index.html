🔊 提示方式

网页版：页面开着才会提醒。装成手机 App 后会用系统闹钟，App 关掉也会响。
手机收不到准时提醒？看这里
  1. 允许通知：系统设置 → 应用 → Mochi → 通知，全部打开。
  2. 精确闹钟（Android 12 及以上）：系统设置 → 应用 → Mochi → 「闹钟和提醒」，打开。也可以点上面的“检查精确闹钟权限”。
  3. 电池优化：系统设置 → 电池 → Mochi → 选“不受限制”或“允许后台活动”。
  4. 自启动 / 后台弹出（部分国产手机）：小米在“应用设置 → 自启动”；华为在“应用启动管理”里关掉自动管理并全部允许；OPPO / vivo 在“电池 → 后台耗电管理”里允许；三星在“电池 → 后台使用限制”里把 Mochi 移出休眠名单。
  5. 设置完成后重新打开一次 Mochi，提醒会重新排好。
