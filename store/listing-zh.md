# 商店文案草稿

**应用名称（≤30 字）**：Mochi 智能时间表 – AI 课表

**简短说明（≤80 字）**：拍张照就导入课表，AI 帮你排复习和运动，课前、作业截止准时提醒。

**完整说明**
Mochi 是给学生用的可爱时间表，也是少数能“帮你排”的课表 App。

✨ AI 助手（一个入口，三种用法）
• 拍照导入课表：拍一张课表，识别每一节课，核对后再加入
• 一句话 / 语音添加：“下周三下午三点半数学补习，每周重复”
• 整周重排：把聚会、考试放进去，冲突的旧安排自动挪到空档

📅 清爽的课表
• 日视图 + 周视图，按分钟精确排时间，当前时间红线
• 平板 / 横屏双栏；深色模式；自选主题色
• 多个课表（学校 / 运动 / 备考）、1–4 周轮换、假期自动跳过、重复活动（每月第几个周几）

🔔 不错过
• 课前 N 分钟提醒、作业截止提醒，可选声音 / 振动 / 静音
• 桌面小组件：当前 / 下一节 + 倒计时

📚 会学习
• 复习计划（FSRS 间隔重复）、考试倒计时、运动计划
• 作业与附件、全局搜索、统计

🔒 数据默认只存在你的手机上；登录后可选云同步。无广告。

# Data safety 表单要点（以 Google Play 当前表单为准）
- 收集的数据：邮箱（账号）、用户内容（日程 / 作业 / 照片，仅在使用云同步或 AI 时）
- 是否共享给第三方：Google（Gemini，用于 AI 解析）、Supabase（托管，作为服务提供方）
- 传输加密：是（HTTPS）　　可请求删除：是（需先实现账号删除入口）
- 目标受众：含学生；按当前规定确认是否面向 13 岁以下
