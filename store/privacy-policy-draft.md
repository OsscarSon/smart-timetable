## 1. 我们处理哪些数据
- **只在你的设备上**：课表、活动、作业、提醒、学习与运动计划、设置、作业 / 课程附件。不登录账号时，这些数据不会离开你的设备。
- **登录账号后（可选）**：邮箱、以及上面这些数据会同步到我们使用的 Supabase 云服务（〔区域〕），以便你在多台设备间同步；附件文件存放在私有存储空间，只有你本人能读写。
- **使用 AI 功能时（可选）**：你输入的文字、课表照片、以及当前课表 / 作业的必要内容会发送到我们的服务器，再转发给 Google Gemini（付费 API）进行解析和排程。〔确认：已使用开启结算的付费层，Google 不会将 API 内容用于改进其产品——请以 Google 当前条款为准〕。AI 只返回建议，不会直接修改你的数据。
- **通知**：提醒由你的设备在本机生成，不经过我们的服务器。

## 2. 我们不做的事
不展示广告；不出售你的数据；不用你的数据训练我们自己的模型；不读取通讯录、位置信息。

## 3. 保存期限与删除
- 本机数据：卸载 App 或在设置里清除即删除。
- 云端数据：保存到你删除账号为止。〔删除账号的方式：App 内「设置 → 账号与同步 → 删除账号」/ 网页链接 〕（**请先实现该功能，见 README**）
- 发给 AI 的内容：我们的服务器不保存；限流只记录调用次数（按账号或 IP）。〔Google 对 API 数据的保留期以其条款为准〕

## 4. 儿童
本应用面向学生，可能被 13–18 岁用户使用。未成年人使用云同步和 AI 功能前应取得监护人同意。〔按目标地区法规（如 COPPA、GDPR-K）核对〕

## 5. 你的权利
你可以随时导出备份、更正或删除数据、退出登录。〔按适用法律补充〕

## 6. 变更
更新政策会在本页公布。
